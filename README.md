
# Trader Performance vs Market Sentiment Analysis

## Project Overview
This project analyzes the relationship between Bitcoin market sentiment (Fear/Greed Index) and trader performance using Hyperliquid trading data.

---

## Dataset
1. Historical Trading Data (Hyperliquid)
2. Fear/Greed Sentiment Index

---

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

##  Key Steps
- Data cleaning and preprocessing
- Date alignment between datasets
- Merging sentiment with trading data
- Exploratory Data Analysis (EDA)
- Performance analysis based on sentiment

---

## Key Insights
- Extreme Greed shows highest profitability
- Fear periods show lower win rates
- Trader behavior changes based on sentiment
- Risk increases during Fear phases

---

## Strategy Recommendations
- Reduce leverage during Fear periods
- Increase caution during high volatility
- Focus on quality trades in Fear markets
